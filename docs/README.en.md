# Rektor · Unity School Tycoon · 0.5.0

Six independent save slots with backups, three difficulties, unlimited-funds Sandbox, settings, touch controls and a twelve-chapter guided campaign. 146 subjects, regional weekly plans, 200 custom electives, 17 room types and six floors with real stairs. New campaigns start with basic furniture; 57 item types unlock progressively and develop rooms through five tiers. Decoration follows functional equipment.

Open in Unity 6000.0.65f1, open `Assets/Scenes/Campus.unity` and press Play. Use the main menu to choose a save, difficulty and director. On mobile, Build and Manage can collapse.

Domain tests and compilation against official Unity APIs pass. The actual Unity/Android build is blocked by missing license activation, both locally and in the repository's Actions configuration. No APK or successful device playtest is claimed. [Android instructions](ANDROID.md) · [Validation](VALIDATION.md).

The model previews come from the same C# art recipes rendered in Blender; the menu illustration is generated artwork. They are not Unity gameplay captures.

Older valid saves import into free slot 1 and retain their existing economy, progress and furniture. New campaigns use the new progression. Concept: KoSch / The School Simulation. No distribution licence for the original source has yet been selected.
