# Curriculum and school towers · 0.5

146 built-in courses across ten groups. All 43 currently listed AP subjects are included. Up to 200 additional local electives can be created and stored in each save. These are configurable simulation courses, not certified real-world curricula. Germany and the USA have local variations.

Each class has thirty lesson slots (Monday–Friday, six each day), one teacher and a course level. Course marks belong to pupils and remain when their timetable changes. Exams average only scheduled courses. Advanced courses consume per-pupil, per-lesson supplies.

A specialist room accommodates one whole class per lesson, in stable classroom-ID order with nearby floors preferred. If fully reserved, the next class studies theory at home.

Six floors are possible. Every upper tile needs a room directly below. Gardens stay on the ground. Stairwells must align exactly; only matching stair tiles create vertical routes. Supporting rooms and access stairwells cannot be removed. Each floor adds 20% construction and 10% upkeep.

School visions rotate yearly. One project per year; ten consecutive sustainable days meet the goals. Unfinished projects expire at year end. Projects, exams, pupil progression and courses continue after the initial grants.
